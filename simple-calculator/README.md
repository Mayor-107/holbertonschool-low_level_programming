# Simple Calculator

A terminal-based interactive calculator built in C as part of the Holberton School curriculum. 
This project focuses on program structure, menu-driven loops, conditionals, functions, and 
proper input handling using `scanf`.

## Compile Command

To compile the program with the required strict compiler flags and zero warnings, run the following command:

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 calculator.c -o calculator

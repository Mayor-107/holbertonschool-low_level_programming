# C - Variables, if, else, while

This directory contains C - program files in regards Variables, if, else, while statements.

* `0-positive_or_negative.c`: Assigns a random number to the variable n each time it is executed, whether positive or negative.
* `1-last_digit.c`: Program assigns a random number to the variable n each time it is executed.
* `2-print_alphabet.c`: This program prints the alphabet in lowercase, followed by a new line.
* `3-print_alphabets.c`: Program prints the alphabet in lowercase, and then in uppercase, followed by a new line.
* `4-print_alphabt.c`: Program prints the alphabet in lowercase, followed by a new line except for 'q' and 'e'.
* `5-print_numbers.c`: Program prints all single digit numbers of base 10 starting from 0, followed by a new line.
* `6-print_numberz.c`: Prints all single digit numbers of base 10 starting from 0, followed by a new line.
* `7-print_tebahpla.c`: Prints the lowercase alphabet in reverse, followed by a new line.
* `8-print_base16.c`: Prints all numbers from base 16 in lowercase, followed by a new line.

# C - Hello, World

This directory contains shell scripts in regards to the low-level language which is C.

* `0-preprocessor`: This script runs a C file through the preprocessor and saves the results to another file.
* `1-compiler`: This script compiles a C file but does not link.
* `2-assembler`: Generates the assembly code of a C code and saves it in an output file.
* `3-name`: Compiles a C file and creates an executable named cisfun.
* `4-puts.c`: Prints exactly "Programming is like building a multilingual puzzle", followed by a new line.
